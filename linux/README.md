# Mx VPN for Linux Mint

Simple WireGuard desktop client using Linux Mint's NetworkManager. The package is architecture-independent Python/GTK code; it uses native distribution packages on x64 or ARM64.

## Install and connect

Download `mxvpn_0.1.0-1_all.deb` from the [public release](https://github.com/macsinjobs-oss/Mx-VPN/releases/tag/v0.1.0), open it with Linux Mint's package installer, and install. For terminal installation, use `sudo apt install ./mxvpn_0.1.0-1_all.deb` so dependencies are installed too.

Open **Mx VPN** from the applications menu. Click **Import config**, choose a private WireGuard `.conf` generated by your own provider account, then **Connect**. Authorize the operation through Mint's normal authentication prompt if requested. **Disconnect** stops the selected Mx VPN connection. Switching to another Mx profile disconnects the previous active Mx profile; unrelated connections are not explicitly changed.

For Houston, generate your own Proton configuration for US-FREE#44, #45 or #47; Proton identified these as active free Houston servers on October 12, 2026. The package contains no provider config or account credentials. Generate a separate profile per device and respect your provider's simultaneous-connection limits.

NetworkManager stores imported secrets using its protected system profile storage and limits the profile to the importing user. Import copies are temporary owner-only files, removed after import. Keep your original `.conf` private; delete its plaintext download copy after successful import if you have a secure backup.

## Scope

Targets Linux Mint 21/22 and compatible Ubuntu 22.04/24.04 desktops with NetworkManager, GTK3 and Python3. NetworkManager/polkit provide authorization; the app installs no custom root service, permissive sudo rule or autoconnect profile. Closing the app leaves an active VPN connected; use Disconnect first when you want to stop it.

“VPN tunnel active” means NetworkManager activated the WireGuard interface. Confirm your exit IP before relying on your provider connection. There is no kill-switch implementation or public-IP telemetry in this client. DNS/IPv6 behavior follows the imported profile and NetworkManager. This package does not establish leak-prevention guarantees.

## Build and tests

`bash linux/build-deb.sh` builds the `.deb` on Debian/Ubuntu. `python3 -m unittest discover -s linux/tests -p test_core.py -v` runs parser/backend tests. GTK control tests run under Xvfb. Linux integration tests use isolated network/mount namespaces and a local WireGuard peer with generated test-only keys; no Proton credentials enter CI.
